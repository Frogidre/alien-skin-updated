# Alien Skin v2 (Fabric 1.21.11, client-only)
- Grey alien: huge head, thin torso, long arms (model reshaped with ModelPart scales).
- Toggle: press K (rebind in Controls > Alien Skin).
- Simple Voice Chat (optional): mouth opens/closes when you or others talk.
- Build: ./gradlew build  -> build/libs/alien-skin-2.0.0.jar
  No gradlew? `gradle wrapper --gradle-version 9.2.1`
- Textures: src/main/resources/assets/alienskin/textures/entity/alien.png and alien_talk.png (64x64)
